# Controls Crash Course

An interactive control theory crash course for software engineers. It starts with
classical time- and frequency-domain analysis and works up to whole-body control of
a 7-DOF robot arm.

Each chapter pairs a short explanation with interactive widgets that run right in the
page. Change a parameter, watch the system respond, and build intuition before the
math gets heavy.

## Chapters

1. [Time Domain and State Space](time_domain.md): first- and second-order systems, the
   state-space form, linearization, and discrete time.
2. Frequency Domain *(coming soon)*: the Laplace transform, transfer functions, poles and
   zeros, and Bode plots.
3. Feedback and Joint Control *(coming soon)*: PID control, root locus, and stability
   margins.
4. Kinematics *(coming soon)*: rotations and transforms, forward kinematics, the
   Jacobian, singularities, inverse kinematics, and redundancy.
5. Rigid-Body Dynamics *(coming soon)*: the manipulator equations, Pinocchio's
   algorithms, and computed-torque control.
6. Task-Space Control *(coming soon)*: operational-space control, null-space
   projection, and impedance control.
7. Whole-Body Control *(coming soon)*: quadratic programming and task-space inverse
   dynamics on a 7-DOF arm.
